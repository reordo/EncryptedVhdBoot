Clone the repository and all required source dependencies with:

git clone https://github.com/reordo/EncryptedVhdBoot.git
cd EncryptedVhdBoot
tools\Initialize-Repository.ps1

Each binary release also provides an EncryptedVhdBoot-v1.0.0-source.zip asset
containing the project tree and the complete contents of these required source
revisions. Its SOURCE-MANIFEST.txt records every included commit.

The prebuilt vhdboot image is derived from the official Ventoy `ventoy/vhdiso`
Win10Based v3.0 image:

https://github.com/ventoy/vhdiso/releases/tag/v3.0

Required upstream image SHA-256:
6161d63520eb72bd1d5cb99aa9a771cc8b93ad9718de637b7d2195911dd224ef

Upstream ventoy_vhdboot-v3.0.zip SHA-256:

The upstream image is an external build input. It and the non-open-source
Microsoft boot files inside it are not part of the Git source tree.
